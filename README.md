# 수업 관리 앱

선생님은 **출석 → 미리 채워진 진도 확인 → 숙제 체크**만 하면,
저녁에 학부모님께 출결·수업 리포트 문자(또는 알림톡)가 자동으로 나가는 학원용 웹앱이에요.
학부모님은 앱을 쓰지 않고 문자만 받아요.

- Cloudflare Workers + D1(데이터) + R2(사진·영상) + 10분마다 예약 실행 — **무료 플랜**
- GitHub에 올리면 자동 배포
- 시간은 모두 한국 시간 기준

---

## 배포 순서 (한 번만)

> 화면을 캡처해서 보내 주시면 어디를 누를지 하나씩 알려 드릴게요.
> 비밀번호·결제 정보는 원장님이 직접 입력하세요.

### 1. GitHub에 올리기
1. github.com → 오른쪽 위 **+** → **New repository**
2. 이름: `class-manager`, **Private** 선택 → **Create repository**
3. 화면의 **uploading an existing file** 글자 클릭
4. 압축을 푼 폴더 **안의 파일과 폴더 전부**를 끌어다 놓기 → 아래 **Commit changes**

### 2. Cloudflare 데이터베이스(D1) 만들기
1. dash.cloudflare.com → 왼쪽 **Storage & Databases → D1 SQL Database** → **Create Database**
2. 이름: `class-manager-db` → **Create**
3. 화면에 보이는 **Database ID**(긴 영문·숫자)를 복사
4. GitHub 저장소에서 `wrangler.toml` 클릭 → 연필(✏️) 아이콘 → `여기에_D1_ID` 자리에 붙여 넣기 → **Commit changes**

### 3. 사진·영상 저장소(R2) 켜기
1. 왼쪽 **R2 Object Storage** → **Purchase R2 Plan**(무료 10GB, 결제 수단 등록만 필요)
2. **Create bucket** → 이름 `class-manager-media` → **Create bucket**

### 4. Cloudflare에 GitHub 연결 (자동 배포)
1. 왼쪽 **Workers & Pages** → **Create** → **Import a repository**
2. GitHub 연결 → `class-manager` 저장소 선택
3. 설정은 그대로 두고 **Deploy** (Deploy command: `npx wrangler deploy`)
4. 끝나면 `https://class-manager.○○○.workers.dev` 주소가 생겨요. 이게 앱 주소예요.

### 5. 솔라피 열쇠 넣기 (코드·채팅에 절대 넣지 않기)
1. Workers & Pages → **class-manager** → **Settings** → **Variables and Secrets** → **+ Add**
2. Type: **Secret** 으로 아래 3개를 하나씩 추가

| 이름 | 넣을 값 |
|---|---|
| `SOLAPI_API_KEY` | 솔라피 API Key |
| `SOLAPI_API_SECRET` | 솔라피 API Secret |
| `SOLAPI_SENDER` | 솔라피에 등록한 발신번호 (숫자만) |

3. **Deploy** 누르기 → 앱의 **관리 → 발송 방식**에서 "솔라피 연결됨"과 잔액이 보이면 성공
4. **나에게 테스트 문자** 버튼으로 확인

### 6. 처음 접속
앱 주소로 들어가면 **학원 이름 + 원장 비밀번호**를 정하는 화면이 나와요. 그다음 관리 화면에서:
1. 선생님 추가 (선생님마다 비밀번호)
2. 과정 이름 확인 (기본: 중등 / 초등 리딩 / 초등 파닉스)
3. **진도표** 탭 → 새 진도표 → 엑셀 올리기 또는 붙여 넣기
4. 반 만들기 (그룹/개별, 요일, 시간, 선생님, 과정 → 진도표 → 시작 차시)
5. 학생 → **명단 불러오기** (엑셀·PDF·붙여 넣기)

## 하루 흐름

| 시간 | 하는 일 |
|---|---|
| 수업 시작 | 오늘 수업 → 출석/지각/결석 (누르는 즉시 저장) |
| 수업 중 | 미리 채워진 진도 확인, 숙제 완료/미흡/미제출 체크, 필요하면 한마디·사진 |
| 저녁 8:00 | 그날 기록으로 메시지 미리보기 자동 생성 |
| ~ 8:30 | 학부모 메시지 탭에서 문구 고치기 / 보내지 않을 학생 체크 해제 |
| 8:30 | 체크된 메시지만 자동 발송 |

시간은 관리 → 발송 일정에서 바꿀 수 있어요.

## 알아 두면 좋은 점
- **입력은 사라지지 않아요.** 입력하는 즉시 휴대폰에 먼저 보관하고 2초 뒤 서버에 저장해요. 인터넷이 끊기거나 창을 닫아도, 다시 열면 그대로 복구 후 저장돼요.
- **새 버전 배포**: GitHub에 고친 파일을 올리면 자동 배포되고, 선생님 휴대폰도 1분 안에(또는 앱을 다시 열 때) 새 화면으로 바뀌어요. 화면 왼쪽 아래에 버전 번호가 보여요.
- **전송됨 ✓** 은 솔라피가 접수한 시각이에요. 실제 도착 여부는 솔라피 사이트의 발송 내역에서 볼 수 있어요.
- **알림톡**은 카카오가 승인한 문구만 보낼 수 있어서, 선생님이 메시지를 직접 고치면 그 메시지는 문자(LMS)로 나가요.
- 저장 안 하고 지나간 날도, 출석한 반은 저녁 8시에 미리 채워진 진도를 그날 기록으로 남겨서 다음 수업이 다음 차시로 넘어가요.
- 사진·영상은 30일 뒤 자동으로 지워져요.
- 무료 플랜 기준 하루 요청 10만 건까지라 학원 한 곳에는 충분해요.

## 폴더 구성
```
wrangler.toml      Cloudflare 설정 (D1 ID 한 곳만 바꾸기)
src/               서버 (Workers)
  worker.js        시작점 + 10분 예약 실행
  api.js           화면이 부르는 기능들
  messages.js      미리보기 · 발송
  solapi.js        솔라피 문자·알림톡
  media.js         사진·영상 (R2, 영상 재생 호환, 모아 보기 페이지)
  defaults.js      기본 문구 · 쿠션 멘트 · 알림톡 추천 문구
public/            화면
dev/               내 컴퓨터에서 미리 돌려 보는 용도 (배포와 무관)
```
